# RedwoodJS example for Bolio UI

A [RedwoodJS](https://redwoodjs.com) application with Bolio UI already set up.

> **Prerequisites**
>
> - Redwood requires [Node.js](https://nodejs.org/en/) (=20.x) and [Yarn](https://yarnpkg.com/) through Corepack (`corepack enable`)

## Getting started

```bash
yarn install
yarn rw dev
```

See the [RedwoodJS guide](https://bolio-ui.com/docs/guide/bolio-ui-plus-redwoodjs) to set up Bolio UI in your own project.
