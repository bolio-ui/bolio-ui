# TanStack Start example for Bolio UI

A [TanStack Start](https://tanstack.com/start) application with Bolio UI already set up.

## Getting started

```bash
yarn
yarn dev
```

See the [TanStack Start guide](https://bolio-ui.com/docs/guide/bolio-ui-plus-tanstack-start) to set up Bolio UI in your own project.
