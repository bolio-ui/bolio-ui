# Next.js (JavaScript) example for Bolio UI

A [Next.js](https://nextjs.org) application with the Pages Router and Bolio UI already set up.

## Getting started

```bash
yarn
yarn dev
```

Open [http://localhost:3000](http://localhost:3000) to see the result. See the [Next.js guide](https://bolio-ui.com/docs/guide/bolio-ui-plus-nextjs) to set up Bolio UI in your own project.
