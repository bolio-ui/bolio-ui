## TreeSelect

A field that opens a [Tree](/docs/components/tree) to choose one item from nested options, such as a folder, a category or an organization chart. A node with children opens and closes, and a node without children is the one that gets chosen.

<Attributes edit="/content/docs/components/tree-select.mdx">
<Attributes.Title>TreeSelect.Props</Attributes.Title>

| Attribute        | Description                                      | Type                                          | Accepted values | Default   |
| ---------------- | ------------------------------------------------ | --------------------------------------------- | --------------- | --------- |
| **data**         | nodes of the tree, as in [Tree](/docs/components/tree) | `TreeNodeData[]`                        | -               | -         |
| **value**        | value of the chosen node, to control it          | `string \| null`                              | -               | -         |
| **initialValue** | value of the chosen node at the start            | `string \| null`                              | -               | `null`    |
| **onChange**     | called with the value and the node that was chosen | `(value: string, node: TreeNodeData) => void` | -              | -         |
| **placeholder**  | text shown while nothing is chosen               | `string`                                      | -               | `Select`  |
| **treeLabel**    | accessible name of the tree                      | `string`                                      | -               | `Options` |
| **disabled**     | disable the field                                | `boolean`                                     | -               | `false`   |
| **type**         | color of the field                               | `NormalTypes`                                 | `'default' \| 'secondary' \| 'success' \| 'warning' \| 'error'` | `default` |
| **rounded**      | round the corners                                | `boolean`                                     | -               | `false`   |
| ...              | native props of `button`                         | `ButtonHTMLAttributes`                        | `'id', 'aria-label', ...` | -  |

<Attributes.Title>Ref</Attributes.Title>

The `ref` points at the `button` of the field.

<Attributes.Title>Accessibility</Attributes.Title>

The field is a button with `aria-haspopup="tree"` and `aria-expanded`. The tree takes the focus when it opens, on the chosen node or else on the first one, and Escape closes it and gives the focus back to the field. Give the field a name with `aria-label` or a label, because its text is the chosen item and not what it is for. The keys inside are those of [Tree](/docs/components/tree).

</Attributes>
