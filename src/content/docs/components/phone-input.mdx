## PhoneInput

A phone number field with a country select that sets the calling code. The value is the international number as a plus sign and digits, such as `+5511999999999`, or an empty string while there are no digits.

  return (

      <Grid xs={24} sm={12}>
        <PhoneInput value={value} onChange={setValue} />
      </Grid>
      <Grid>

  )
}

<Attributes edit="/content/docs/components/phone-input.mdx">
<Attributes.Title>PhoneInput.Props</Attributes.Title>

| Property           | Description                                       | Type                         | Accepted values | Default        |
| ------------------ | ------------------------------------------------- | ---------------------------- | --------------- | -------------- |
| **value**          | controlled number, such as `+5511999999999`       | `string`                     | -               | -              |
| **initialValue**   | initial number                                    | `string`                     | -               | `''`           |
| **onChange**       | called with the number, or `''` when it is empty  | `(value: string) => void`    | -               | -              |
| **countries**      | countries in the select                           | `PhoneCountry[]`             | -               | `phoneCountries` |
| **defaultCountry** | ISO code used while the number is empty           | `string`                     | -               | `US`           |
| **placeholder**    | text and accessible name of the number field      | `string`                     | -               | `Phone number` |
| **countryLabel**   | accessible name of the country select             | `string`                     | -               | `Country`      |
| **disabled**       | disable both fields                               | `boolean`                    | -               | `false`        |
| **type**           | color of the fields                               | `NormalTypes`                | `'default' \| 'secondary' \| 'success' \| 'warning' \| 'error'` | `default` |
| **rounded**        | round the corners                                 | `boolean`                    | -               | `false`        |
| ...                | native props of `div`                             | `HTMLAttributes`             | -               | -              |

</Attributes>
