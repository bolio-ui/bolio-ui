## Marquee

Loop content horizontally without end.

<Playground
  title="General"
  desc="Pauses on hover and stops when the user prefers reduced motion."

<Attributes.Title>Marquee.Props</Attributes.Title>

| Attribute        | Description                | Type             | Accepted values | Default |
| ---------------- | -------------------------- | ---------------- | --------------- | ------- |
| **duration**     | seconds for one full loop  | `number`         | -               | `30`    |
| **pauseOnHover** | pause while hovering       | `boolean`        | -               | `true`  |
| **reverse**      | run in the other direction | `boolean`        | -               | `false` |
| **gap**          | space between items        | `string`         | -               | `2rem`  |
| ...              | native props               | `HTMLAttributes` | -               | -       |
