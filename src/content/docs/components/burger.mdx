## Burger

A button of three lines that turns into a cross, to open and close a menu. It sets `aria-expanded` from `opened`, and the lines stop moving when the user prefers reduced motion.

<Playground
  desc="Click to switch between the lines and the cross. Keep the name in step with the state."
  scope={{ Burger, Grid, Text }}
  code={`
() => {
  const [opened, setOpened] = React.useState(false)
  return (
    <Grid.Container gap={2} alignItems="center">
      <Grid>
        <Burger
          label={opened ? 'Close menu' : 'Open menu'}
          opened={opened}
          onClick={() => setOpened(!opened)}
        />
      </Grid>
      <Grid>
        <Text p b my={0}>{opened ? 'Menu open' : 'Menu closed'}</Text>
      </Grid>
    </Grid.Container>
  )
}
`}
/>
