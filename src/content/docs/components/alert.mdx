Show a message that stays in the page, with an optional title, icon and close button.

<Playground
  title="Dismissible"
  desc="`onClose` shows a close button. Hide the alert in your state, and bring it back when the cause returns."
  scope={{ Alert, Button }}
  code={`
() => {
  const [open, setOpen] = React.useState(true)
  return open ? (
    <Alert type="info" light title="New version" onClose={() => setOpen(false)}>
      Reload the page to get the latest changes.
    </Alert>
  ) : (
    <Button auto scale={0.75} onClick={() => setOpen(true)}>Show the alert again</Button>
  )
}
`}
/>

<Attributes edit="/content/docs/components/alert.mdx">
<Attributes.Title>Alert.Props</Attributes.Title>

| Attribute      | Description                                   | Type                                                                          | Accepted values | Default   |
| -------------- | --------------------------------------------- | ----------------------------------------------------------------------------- | --------------- | --------- |
| **type**       | color of the alert                            | `'default' \| 'primary' \| 'secondary' \| 'success' \| 'warning' \| 'error' \| 'info'` | -               | `default` |
| **title**      | bold first line                               | `ReactNode`                                                                   | -               | -         |
| **icon**       | element before the text                       | `ReactNode`                                                                   | -               | -         |
| **filled**     | solid color                                   | `boolean`                                                                     | -               | `false`   |
| **light**      | tinted background                             | `boolean`                                                                     | -               | `false`   |
| **subtle**     | text only, no border                          | `boolean`                                                                     | -               | `false`   |
| **onClose**    | shows a close button and calls it on click    | `() => void`                                                                  | -               | -         |
| **closeLabel** | accessible name of the close button           | `string`                                                                      | -               | `Close`   |
| **role**       | defaults to `alert` for errors and warnings, `status` otherwise | `string`                                                    | -               | -         |
| ...            | native props                                  | `HTMLAttributes`                                                              | -               | -         |

</Attributes>
