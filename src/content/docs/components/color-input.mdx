## Color Input

A field for a hex color. The swatch on the left shows the color and opens a
<a href="/docs/components/color-picker">Color Picker</a> in a popover. You can
also type the code.

<Attributes.Title>Typing</Attributes.Title>

The color changes as soon as the text holds six digits, with or without the `#`. A short code like `#abc` is read when the field loses the focus, and becomes `#aabbcc`. Any other text is dropped on blur, and the field goes back to the current color. The field always holds a color, so it cannot be left empty.

<Attributes.Title>Ref</Attributes.Title>

The `ref` points at the `input`.

<Attributes.Title>Accessibility</Attributes.Title>

The field is named by its label, or by `aria-label`. The swatch is a button with `aria-haspopup="dialog"` and `aria-expanded`, named by `pickerLabel`. The picker opens in a dialog with the focus on its square. Escape closes it and puts the focus back on the swatch. The code is also a text in the field, so the color is not conveyed by the swatch alone. See <a href="/docs/components/color-picker">Color Picker</a> for the keys.
