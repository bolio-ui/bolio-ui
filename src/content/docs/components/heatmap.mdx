## Heatmap

A calendar where each day is a square, darker the bigger its value. Use it for activity over weeks, such as commits, check-ins or sales per day.

| Attribute             | Description                                                    | Type                                  | Accepted values                                                            | Default                |
| --------------------- | -------------------------------------------------------------- | ------------------------------------- | -------------------------------------------------------------------------- | ---------------------- |
| **data**              | the value of each day, with `YYYY-MM-DD` keys                  | `Record<string, number>`              | -                                                                          | -                      |
| **startDate**         | first day shown                                                | <Code>string &#124; Date</Code>       | -                                                                          | a year before the end  |
| **endDate**           | last day shown                                                 | <Code>string &#124; Date</Code>       | -                                                                          | today                  |
| **type**              | theme color of the squares                                     | `NormalTypes`                         | `'default', 'primary', 'secondary', 'success', 'warning', 'error', 'info'` | `success`              |
| **colors**            | colors of the levels, from the lowest to the highest           | `string[]`                            | -                                                                          | 4 shades of `type`     |
| **firstDayOfWeek**    | day that starts a week, 0 is Sunday                            | `number`                              | `0` to `6`                                                                 | `1`                    |
| **rectSize**          | side of a square, in pixels                                    | `number`                              | -                                                                          | `12`                   |
| **gap**               | space between squares, in pixels                               | `number`                              | -                                                                          | `3`                    |
| **rectRadius**        | corner radius of a square, in pixels                           | `number`                              | -                                                                          | `2`                    |
| **withMonthLabels**   | name the months above the columns                              | `boolean`                             | -                                                                          | `true`                 |
| **withWeekdayLabels** | name Monday, Wednesday and Friday                              | `boolean`                             | -                                                                          | `true`                 |
| **withLegend**        | show the scale below                                           | `boolean`                             | -                                                                          | `false`                |
| **legendLabels**      | texts at the two ends of the legend                            | `[string, string]`                    | -                                                                          | `Less`, `More`         |
| **locale**            | language of the months and the weekdays                        | `string`                              | -                                                                          | `en-US`                |

| **valueLabel**        | text of the hover title of a day                               | `(date: string, value: number) => string` | -                                                                      | `date: value`          |
| ...                   | native props, passed to the `svg`                              | `SVGAttributes`                       | `'aria-label', 'className', ...`                                           | -                      |

<Attributes.Title>Ref</Attributes.Title>

The `ref` points at the `svg`.

<Attributes.Title>Accessibility</Attributes.Title>

Value is shown by color only, and each square has a hover title with its date and value. Describe the pattern with `aria-label` or `aria-labelledby`, such as "Commits in 2026, busiest in March". With a name it is an image. Without one it is hidden from assistive technology.

For the exact numbers, offer the same data in a `Table` next to the heatmap.
