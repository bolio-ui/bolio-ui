## Schedule

A calendar of events, by day, week or month. Events sit on a grid of hours, side by side when they overlap, and all-day events have a row of their own. Use it for appointments, shifts, bookings and meetings.

```ts
type ScheduleEvent = {
  id: string | number
  title: string
  start: Date
  end: Date
  color?: string // any CSS color, the theme primary when missing

```

<Attributes.Title>Accessibility</Attributes.Title>

The header buttons and the views are real buttons, and the view that is on has `aria-pressed`. Each day of the grid is a group named by its date, and each event is a button named by its title and time.

With `onSlotClick`, the slots are one tab stop, moved with the arrow keys: Up and Down between hours, Left and Right between days, Home and End to the first and last hour. In the month view the day numbers work the same way, and Home and End go to the start and end of the week.

Dragging and resizing events are not part of this component.
