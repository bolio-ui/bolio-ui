## Command

A searchable list of actions, opened with a shortcut.

<Playground
  title="General"
  desc="Type to filter, use the arrow keys to move and Enter to run the action."
  scope={{ Command, Button, useState, Home, Settings }}
  code={`
() => {
  const [open, setOpen] = useState(false)
  const items = [
    { value: 'home', label: 'Go to home', icon: <Home />, onSelect: () => console.log('home') },
    { value: 'settings', label: 'Open settings', icon: <Settings />, hint: 'G S', onSelect: () => console.log('settings') },
    { value: 'theme', label: 'Switch theme', hint: 'T', onSelect: () => console.log('theme') }
  ]
  return (
    <>
      <Button auto onClick={() => setOpen(true)}>Open command</Button>
      <Command visible={open} onClose={() => setOpen(false)} items={items} />
    </>
  )
}
`}
/>

<Playground
  title="With Shortcut"
  desc="Open it with Cmd+K, or Ctrl+K on Windows and Linux, using `useKeyboard`."
  scope={{ Command, Keyboard, useKeyboard, KeyCode, KeyMod, useState }}
  code={`
() => {
  const [open, setOpen] = useState(false)
  useKeyboard(
    (event) => {
      event.preventDefault()
      setOpen(true)
    },
    [KeyCode.KEY_K, KeyMod.CtrlCmd]
  )
  const items = [
    { value: 'new', label: 'New project', onSelect: () => console.log('new') },
    { value: 'invite', label: 'Invite a teammate', onSelect: () => console.log('invite') }
  ]
  return (
    <>
      <Keyboard command>K</Keyboard>
      <Command visible={open} onClose={() => setOpen(false)} items={items} />
    </>
  )
}
`}
/>

| Attribute       | Description                         | Type                 | Accepted values | Default                        |
| --------------- | ----------------------------------- | -------------------- | --------------- | ------------------------------ |
| **visible**     | show the palette                    | `boolean`            | -               | -                              |
| **onClose**     | called on Esc, backdrop or selection | `() => void`        | -               | -                              |
| **items**       | actions to list                     | `CommandItem[]`      | -               | -                              |
| **placeholder** | placeholder of the search field     | `string`             | -               | `Type a command or search`     |
| **emptyText**   | shown when nothing matches          | `string`             | -               | `No results. Try another word.` |
