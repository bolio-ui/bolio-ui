## Copy Button

Copies a text to the clipboard and tells you when it is done. It draws nothing
by itself: you return the trigger, so it works with a Button, a link or an icon.

<Playground
  desc="Call `copy` from the trigger. `copied` is `true` for a second after the copy."
  scope={{ CopyButton, Button }}
  code={`
<CopyButton value="yarn add @bolio-ui/core">
  {({ copied, copy }) => (
    <Button auto scale={0.75} onClick={copy}>
      {copied ? 'Copied' : 'Copy'}
    </Button>
  )}
</CopyButton>
`}
/>

<Playground
  title="Timeout"
  desc="Use `timeout` to change how long `copied` lasts, in milliseconds."
  scope={{ CopyButton, Button }}
  code={`
<CopyButton value="hello@bolio-ui.com" timeout={3000}>
  {({ copied, copy }) => (
    <Button auto scale={0.75} type={copied ? 'success' : 'default'} onClick={copy}>
      {copied ? 'Email copied' : 'Copy email'}
    </Button>
  )}
</CopyButton>
`}
/>

<Attributes edit="/content/docs/components/copy-button.mdx">
<Attributes.Title>CopyButton.Props</Attributes.Title>

| Attribute    | Description                                                | Type                                   | Accepted values | Default |
| ------------ | ---------------------------------------------------------- | -------------------------------------- | --------------- | ------- |
| **value**    | text copied to the clipboard                               | `string`                               | -               | -       |
| **timeout**  | milliseconds that `copied` stays `true` after a copy       | `number`                               | -               | `1000`  |
| **children** | function that returns the trigger                          | `({ copied, copy }) => ReactNode`      | -               | -       |

<Attributes.Title>Accessibility</Attributes.Title>

The component adds no element, so the trigger you return carries the semantics. Use a real button, and change its text when `copied` is `true` so the new state is clear.

</Attributes>
