## AppShell

The frame of an app. It places a header, a navbar, the main content, an aside and a footer in a grid, and gives the main area its own scroll. Every slot is optional, and one that you do not render takes no room.

The shell is as tall as `height`, which is the whole screen by default. Put it in a container with a fixed height, or give it a `height`, to see it inside a page.

<Attributes edit="/content/docs/components/app-shell.mdx">
<Attributes.Title>AppShell.Props</Attributes.Title>

| Attribute  | Description                                 | Type               | Accepted values | Default   |
| ---------- | ------------------------------------------- | ------------------ | --------------- | --------- |
| **height** | height of the whole shell                   | `number` or `string` | -             | `'100vh'` |
| ...        | native props, passed to the root element    | `HTMLAttributes`   | `'id', 'className', ...` | - |

<Attributes.Title>AppShell.Header.Props</Attributes.Title>

| Attribute  | Description                    | Type                 | Accepted values | Default |
| ---------- | ------------------------------ | -------------------- | --------------- | ------- |
| **height** | height of the header           | `number` or `string` | -               | content |
| ...        | native props, passed to the `header` | `HTMLAttributes` | `'id', 'className', ...` | - |

`AppShell.Footer` takes the same props and renders a `footer`.

<Attributes.Title>AppShell.Navbar.Props</Attributes.Title>

| Attribute | Description                    | Type                 | Accepted values | Default |
| --------- | ------------------------------ | -------------------- | --------------- | ------- |
| **width** | width of the navbar            | `number` or `string` | -               | content |
| ...       | native props, passed to the `nav` | `HTMLAttributes`  | `'id', 'className', ...` | - |

`AppShell.Aside` takes the same props and renders an `aside`. `AppShell.Main` takes only the native props and renders a `main`.

<Attributes.Title>Ref</Attributes.Title>

The `ref` of each part points at its element.

<Attributes.Title>Accessibility</Attributes.Title>

Each slot renders a landmark: `header`, `nav`, `main`, `aside` and `footer`, so screen reader users can jump between them. Set an `aria-label` on the navbar and the aside to name them, mainly when the page has more than one navigation.

</Attributes>
