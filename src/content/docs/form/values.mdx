## Form values

`initialValues` sets the first values and the ones `reset` goes back to. `form.values` always holds the current ones.

<Spacer h={2} />

### Change values

`setFieldValue(path, value)` changes one field and `setValues(values)` merges several at once. Both keep the other fields.

<Playground
  desc="Fill the form from code, then reset it."
  scope={{ Button, Input, Spacer, Text, useForm }}
  code={`
() => {
  const form = useForm({ initialValues: { name: '', city: '' } })
  return (
    <>
      <Input width="100%" label="Name" {...form.getInputProps('name')} />
      <Spacer h={0.5} />
      <Input width="100%" label="City" {...form.getInputProps('city')} />
      <Spacer h={1} />
      <Button auto scale={1 / 2} onClick={() => form.setFieldValue('name', 'Ana')}>Set name</Button>
      <Button auto scale={1 / 2} ml="10px" onClick={() => form.setValues({ name: 'Bia', city: 'Lisbon' })}>Set both</Button>
      <Button auto scale={1 / 2} ml="10px" onClick={form.reset}>Reset</Button>
      <Text>{JSON.stringify(form.values)}</Text>
    </>
  )
}
`}
/>

<Spacer h={2} />

### Reset

`reset()` restores the initial values and clears the errors and the touched state.
Use `onReset` on the `form` element, or on a reset button, to do the same without calling it yourself.

<Spacer h={2} />

### Submit

`onSubmit(handleValues)` returns the handler for the `form` element. It calls `preventDefault`, validates, and gives `handleValues` the current values.

```tsx
<form onSubmit={form.onSubmit((values) => save(values))} onReset={form.onReset}>
```

<Attributes edit="/content/docs/form/values.mdx">
<Attributes.Title>Values</Attributes.Title>

| Name                  | Description                                  | Type                                    |
| --------------------- | -------------------------------------------- | --------------------------------------- |
| **values**            | current values                               | `Values`                                |
| **setFieldValue**     | change one field by path                     | `(path: string, value: unknown) => void` |
| **setValues**         | merge values into the current ones           | `(values: Partial<Values>) => void`     |
| **reset**             | restore the initial values and clear errors  | `() => void`                            |
| **onReset**           | `reset` as an event handler                  | `(event?: FormEvent) => void`           |

</Attributes>
