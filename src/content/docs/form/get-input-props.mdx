## getInputProps

`form.getInputProps(path)` returns the props a field needs, so you spread it instead of wiring each handler.

<Spacer h={2} />

### Fields that receive a value

Most fields take `value` and call `onChange` with the new value: Select, Slider, NumberInput, DatePicker, TagsInput, Rating and others. `Radio.Group` also takes `value` and `onChange`.
Input and Textarea call `onChange` with the event, and `getInputProps` reads `event.target.value` for you.

<Playground
  desc="Select and Slider take the spread. Radio.Group gets its value and handler."
  scope={{ Radio, Select, Slider, Spacer, Text, useForm }}
  code={`
() => {
  const form = useForm({
    initialValues: { plan: 'free', size: 'm', volume: 30 }
  })
  return (
    <>
      <Select width="100%" {...form.getInputProps('plan')}>
        <Select.Option value="free">Free</Select.Option>
        <Select.Option value="pro">Pro</Select.Option>
      </Select>
      <Spacer h={1} />
      <Radio.Group
        value={form.values.size}
        onChange={(value) => form.setFieldValue('size', value)}
      >
        <Radio value="s">Small</Radio>
        <Radio value="m">Medium</Radio>
      </Radio.Group>
      <Spacer h={1} />
      <Slider {...form.getInputProps('volume')} />
      <Text>{JSON.stringify(form.values)}</Text>
    </>
  )
}
`}
/>

<Spacer h={2} />

### Checkboxes

A checkbox has no `value`, it has `checked`. Pass `{ type: 'checkbox' }` and `getInputProps` returns `checked` and reads `event.target.checked`.

<Playground
  title="Checkbox"
  desc="Use the checkbox type for boolean fields."
  scope={{ Checkbox, Spacer, Text, useForm }}
  code={`
() => {
  const form = useForm({ initialValues: { terms: false } })
  return (
    <>
      <Checkbox {...form.getInputProps('terms', { type: 'checkbox' })}>
        I accept the terms
      </Checkbox>
      <Spacer h={0.5} />
      <Text>Accepted: {String(form.values.terms)}</Text>
    </>
  )
}
`}
/>

<Spacer h={2} />

### Showing the error

While a field has an error, `getInputProps` also returns `error` and `errorMessage`. Input, Textarea, NumberInput, TagsInput, Select, Checkbox and Radio show them.
On other fields, pass only `value` and `onChange`, or the extra props reach the DOM as unknown attributes.
`Radio.Group` is one of them, so set its `value` and `onChange` yourself.

<Attributes edit="/content/docs/form/get-input-props.mdx">
<Attributes.Title>getInputProps</Attributes.Title>

```ts
type getInputProps = (
  path: string,
  options?: { type?: 'input' | 'checkbox' }
) => {
  value?: any
  checked?: boolean
  onChange: (valueOrEvent: any) => void
  onBlur: () => void
  error?: boolean
  errorMessage?: string
}
```

<Attributes.Title>InputTypes</Attributes.Title>

| Type             | Returns                                                | Use with                                  |
| ---------------- | ------------------------------------------------------ | ----------------------------------------- |
| **`'input'`**    | `value`, `onChange`, `onBlur`, and the error when set   | every field that takes a value            |
| **`'checkbox'`** | `checked`, `onChange`, `onBlur`, and the error when set | Checkbox                                  |

</Attributes>
