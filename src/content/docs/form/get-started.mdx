## Get started

`useForm` keeps the values, errors and submit of a form in one place and binds them to Bolio UI fields.
It comes with `@bolio-ui/core`, so there is nothing else to install.

<Spacer h={2} />

### Basic form

Pass the initial values and the rules. Spread `getInputProps` on each field and call `onSubmit` with your handler.
The handler only runs when every rule passes.

<Playground
  desc="Submit the empty form to see the errors."
  scope={{ Button, Input, Spacer, Text, isEmail, isNotEmpty, useForm }}
  code={`
() => {
  const [sent, setSent] = React.useState(null)
  const form = useForm({
    initialValues: { name: '', email: '' },
    validate: {
      name: isNotEmpty('Enter your name'),
      email: isEmail('Enter a valid email')
    }
  })
  return (
    <form onSubmit={form.onSubmit(setSent)}>
      <Input width="100%" label="Name" {...form.getInputProps('name')} />
      <Spacer h={0.5} />
      <Input width="100%" label="Email" {...form.getInputProps('email')} />
      <Spacer h={1} />
      <Button auto scale={1 / 2} type="secondary" htmlType="submit">Subscribe</Button>
      {sent && <Text>Sent: {JSON.stringify(sent)}</Text>}
    </form>
  )
}
`}
/>

<Spacer h={2} />

### How it works

- • `values` and `errors` hold the current state. Errors use the same path as their field, such as `user.email`.
- • `getInputProps(path)` returns what a field needs: its value, the change and blur handlers, and the error when there is one.
- • `validate` takes one rule per field. A rule returns the message to show, or `null` when the value is fine.
- • `onSubmit` validates first. It calls your handler with the values, or the optional second handler with the errors.
- • `reset` goes back to the initial values and clears the errors.
