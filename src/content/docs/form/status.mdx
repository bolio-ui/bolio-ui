## Form status

<Spacer h={2} />

### Dirty and touched

A field is dirty when its value differs from the initial one. It is touched after the user changes it or leaves it.
Call `isDirty()` or `isTouched()` for the whole form, or pass a path for one field. `reset()` clears both.

<Playground
  desc="Type in the field, then clear it back to the first value."
  scope={{ Button, Input, Spacer, Text, useForm }}
  code={`
() => {
  const form = useForm({ initialValues: { name: 'Ana' } })
  return (
    <>
      <Input width="100%" label="Name" {...form.getInputProps('name')} />
      <Spacer h={0.5} />
      <Text>Dirty: {String(form.isDirty())}</Text>
      <Text>Touched: {String(form.isTouched('name'))}</Text>
      <Button auto scale={1 / 2} onClick={form.reset}>Reset</Button>
    </>
  )
}
`}
/>

<Spacer h={2} />

### Submitting

When the handler you pass to `onSubmit` returns a promise, `form.submitting` is `true` until it settles.
Use it to disable the button and avoid a second submit.

<Playground
  title="Async submit"
  desc="The button waits for the handler to finish."
  scope={{ Button, Input, Spacer, Text, isNotEmpty, useForm }}
  code={`
() => {
  const [saved, setSaved] = React.useState(false)
  const form = useForm({
    initialValues: { name: '' },
    validate: { name: isNotEmpty('Enter your name') }
  })
  const save = () =>
    new Promise((resolve) => setTimeout(() => { setSaved(true); resolve() }, 1500))
  return (
    <form onSubmit={form.onSubmit(save)}>
      <Input width="100%" label="Name" {...form.getInputProps('name')} />
      <Spacer h={1} />
      <Button auto scale={1 / 2} type="secondary" htmlType="submit" loading={form.submitting}>Save</Button>
      {saved && <Text>Saved.</Text>}
    </form>
  )
}
`}
/>

<Attributes.Title>Status</Attributes.Title>

| Name           | Description                                             | Type                           |
| -------------- | ------------------------------------------------------- | ------------------------------ |
| **isDirty**    | a field, or any field, differs from the initial values  | `(path?: string) => boolean`   |
| **isTouched**  | a field, or any field, was changed or left              | `(path?: string) => boolean`   |
| **submitting** | the handler of `onSubmit` is still running              | `boolean`                      |
