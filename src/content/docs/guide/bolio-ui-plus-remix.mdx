## Example with Remix

<Spacer h={2} />

### Get started with an example

To begin, the most straightforward approach is to utilize one of the provided templates.
These templates come pre-configured with the necessary settings, such as CssBaseline and other fundamental components.

If you're new to GitHub and need guidance on initiating a project using a template,
you can access comprehensive instructions on how to get started on <Link target="_blank" rel="nofollow" color icon href="https://github.com/bolio-ui/bolio-ui/tree/master/examples/create-remix">this example</Link>.

<Spacer h={2} />

### Generate new application

Follow <Link target="_blank" rel="nofollow" color icon href="https://remix.run/">Remix getting started</Link> guide to create new Remix application:

<PackageTabs pnpm="pnpm create remix@latest" npm="npx create-remix@latest" yarn="yarn create remix" bun="bunx create-remix@latest" />

<Spacer h={2} />

### Installation

Install dependencies:

<PackageTabs pnpm="pnpm add @bolio-ui/core" npm="npm i @bolio-ui/core" yarn="yarn add @bolio-ui/core" bun="bun add @bolio-ui/core" />

<Spacer h={2} />

### Setup

Add styles imports, BolioUIProvider and CssBaseline to app/root.tsx:

```jsx
import {
  Links,
  LiveReload,
  Meta,
  Outlet,
  Scripts,
  ScrollRestoration
} from '@remix-run/react'
import { BolioUIProvider, CssBaseline } from '@bolio-ui/core'
import '@bolio-ui/core/styles.css'

export default function App() {
  return (
    <html lang="en">
      <head>
        <meta charSet="utf-8" />
        <meta name="viewport" content="width=device-width, initial-scale=1" />
        <Meta />
        <Links />
      </head>
      <body>
        <BolioUIProvider>
          <CssBaseline />
          <Outlet />
          <ScrollRestoration />
          <Scripts />
          <LiveReload />
        </BolioUIProvider>
      </body>
    </html>
  )
}
```

Ready to go! Start the development server:

<PackageTabs pnpm="pnpm dev" npm="npm run dev" yarn="yarn dev" bun="bun run dev" />
