## Page structure

Four components build the layout of a page, one inside the other:

| Component | What it does |
| --------- | ------------ |
| <a href="/docs/components/section">Section</a> | A band of the page. It can have a background that goes from edge to edge |
| <a href="/docs/components/container">Container</a> | Limits the width and centers the content |
| <a href="/docs/components/row">Row</a> | A flex row |
| <a href="/docs/components/col">Col</a> | A column of the row, sized in twelfths |

### Rules that keep it working

- • Put the `Container` inside the `Section`, not the other way. The band goes from edge to edge and the content stays narrow.
- • The spans in a `Row` should add up to 12 or less. A `Row` does not wrap, so more than 12 makes the columns narrower.
- • Use a new `Row` for each line. If you need items that wrap to the next line by themselves, use <a href="/docs/components/grid">Grid</a>.
- • `Col` needs a `Row` around it. The space set by `gap` on the `Row` is what the columns use.
