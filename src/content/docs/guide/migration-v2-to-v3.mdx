## Migrating to v3

Version 3 drops the styled-jsx runtime: every component now ships plain, static CSS instead of injecting `<style>` tags at render time.
This page lists what changes and what to do about it. The documentation of v2 stays available at <a href="https://v2.bolio-ui.com" rel="noreferrer" target="_blank">v2.bolio-ui.com</a>.

While v3 is in alpha, install it with the `next` tag:

```bash
yarn add @bolio-ui/core@next
```

<Spacer h={2} />

### Breaking changes

#### Import the stylesheet once

Styling used to be injected by styled-jsx on every render. Now it ships as a real `.css` file, so every app needs one import, once, anywhere before the components render:

```jsx
import '@bolio-ui/core/styles.css'
```

Without it, components render unstyled. Add it next to your other top-level imports (`pages/_app.js`, `app/layout.js`, `src/main.tsx`, and so on). See <a href="/docs/guide/getting-started">Getting Started</a> for the setup of each router and framework.

#### `StyledJsxRegistry` and `@bolio-ui/core/next` are gone

The App Router no longer needs a styles registry, because nothing is rendered into the HTML at request time anymore. Remove the wrapper:

```jsx
// v2: app/layout.js
import { BolioUIProvider, CssBaseline } from '@bolio-ui/core'
import { StyledJsxRegistry } from '@bolio-ui/core/next'

export default function RootLayout({ children }) {
  return (
    <html lang="en">
      <body>
        <StyledJsxRegistry>
          <BolioUIProvider>
            <CssBaseline />
            {children}
          </BolioUIProvider>
        </StyledJsxRegistry>
      </body>
    </html>
  )
}

// v3: no registry, just the stylesheet import
import '@bolio-ui/core/styles.css'
import { BolioUIProvider, CssBaseline } from '@bolio-ui/core'

export default function RootLayout({ children }) {
  return (
    <html lang="en">
      <body>
        <BolioUIProvider>
          <CssBaseline />
          {children}
        </BolioUIProvider>
      </body>
    </html>
  )
}
```

A custom server needs nothing beyond serving the stylesheet (or letting your bundler include it) and rendering the app normally: no registry to collect styles from.

#### `styled-jsx` is no longer a dependency

The package does not depend on `styled-jsx` anymore. If nothing else in your app uses it, you can remove it too.

#### Package entry points

`@bolio-ui/core/next` was removed from the `exports` map. These paths work:

| Path | What it is |
| ---- | ---------- |
| `@bolio-ui/core` | All components and hooks |
| `@bolio-ui/core/styles.css` | The stylesheet. Import it once |
| `@bolio-ui/core/css/*` | One stylesheet per component, for apps that want to import only what they use instead of the combined file |
| `@bolio-ui/core/dist/*` | Deep imports of the CommonJS build, as before. They work in Node and in bundlers |
| `@bolio-ui/core/esm/*` | Deep imports of the ES modules build, as before. They are for bundlers: Node cannot load them as they are, so in Node import the package root or `dist/*` |

Other paths are no longer resolved.

#### `Rating` was rebuilt

The old Rating changed its value on hover and then locked on click. Now the value only changes on click or with the arrow keys, and hover shows a preview.

- • `onValueChange` is now `onChange`.
- • `locked` and `onLockedChange` are gone. Use `readOnly` or `disabled`.
- • `initialValue` now defaults to `0`, not `1`.
- • The default color is the warning color, not gray.
- • The types `RatingCount` and `RatingValue` are gone: `count` and `value` are plain numbers.
- • New props: `precision`, `variant`, `emptyIcon`, `clearable`, `highlightSelectedOnly`, `onHoverChange` and `getLabel`.

<Spacer h={2} />

### Changes in behavior

- • **CSS specificity**: every component's styles are now wrapped in a CSS `@layer`, all of them below any unlayered CSS you write. A plain, unlayered selector in your own stylesheet always wins over a component's default style now, with no need for `!important` or extra specificity.
- • **Class names**: internal class names generated by CSS Modules (a hash like `Button-module_root__a1b2c`) replace the old styled-jsx hash. Neither was ever meant to be targeted directly; use the documented props and CSS custom properties instead.

<Spacer h={2} />

### Checklist

1. Install `@bolio-ui/core@next`.
2. Add `import '@bolio-ui/core/styles.css'` once, near your other top-level imports.
3. Remove `StyledJsxRegistry` and the `@bolio-ui/core/next` import from your App Router layout, if you had one.
4. Remove `styled-jsx` from your own dependencies if nothing else in your app uses it.
5. Search your own CSS for selectors that relied on beating a component's specificity; they may no longer need `!important`.
