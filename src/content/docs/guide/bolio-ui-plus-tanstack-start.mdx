## Example with TanStack Start

<Spacer h={2} />

### Get started with an example

To begin, the most straightforward approach is to utilize one of the provided templates.
These templates come pre-configured with the necessary settings, such as CssBaseline and other fundamental components.

If you're new to GitHub and need guidance on initiating a project using a template,
you can access comprehensive instructions on how to get started on <Link target="_blank" rel="nofollow" color icon href="https://github.com/bolio-ui/bolio-ui/tree/master/examples/create-tanstack-start">this example</Link>.

<Spacer h={2} />

### Generate new application

Follow <Link target="_blank" rel="nofollow" color icon href="https://tanstack.com/start/latest/docs/framework/react/getting-started">TanStack Start getting started</Link> guide to create new application:

<PackageTabs pnpm="pnpm dlx @tanstack/cli@latest create my-app" npm="npx @tanstack/cli@latest create my-app" yarn="yarn dlx @tanstack/cli@latest create my-app" bun="bunx @tanstack/cli@latest create my-app" />

<Spacer h={2} />

### Installation

Install dependencies:

<PackageTabs pnpm="pnpm add @bolio-ui/core" npm="npm i @bolio-ui/core" yarn="yarn add @bolio-ui/core" bun="bun add @bolio-ui/core" />

<Spacer h={2} />

### Setup

Add styles imports, BolioUIProvider and CssBaseline to `src/routes/__root.tsx`:

```jsx
import { HeadContent, Scripts, createRootRoute } from '@tanstack/react-router'
import { BolioUIProvider, CssBaseline } from '@bolio-ui/core'
import '@bolio-ui/core/styles.css'

export const Route = createRootRoute({
  shellComponent: RootDocument
})

function RootDocument({ children }: { children: React.ReactNode }) {
  return (
    <html lang="en">
      <head>
        <HeadContent />
      </head>
      <body>
        <BolioUIProvider>
          <CssBaseline />
          {children}
        </BolioUIProvider>
        <Scripts />
      </body>
    </html>
  )
}
```

Ready to go! Start the development server:

<PackageTabs pnpm="pnpm dev" npm="npm run dev" yarn="yarn dev" bun="bun run dev" />
