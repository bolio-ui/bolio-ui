## useTimeout

Run a function after a delay that you can start again or clear.

This is custom React hooks, you need to follow the <Link target="_blank" color href="https://reactjs.org/docs/hooks-rules.html">Basic Rules</Link> when you use it.

<Playground
  desc="The message appears two seconds after the click."
  scope={{ Button, Text, useTimeout }}
  code={`
() => {
  const [visible, setVisible] = React.useState(false)
  const { start } = useTimeout(() => setVisible(true), 2000)
  return (
    <>
      <Button auto scale={0.6} onClick={() => { setVisible(false); start() }}>Start</Button>
      <Text>{visible ? 'Done' : 'Waiting'}</Text>
    </>
  )
}
`}
/>
