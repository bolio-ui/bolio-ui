## useInputState

Keep the value of an input in state, accepting the change event or a value.

This is custom React hooks, you need to follow the <Link target="_blank" color href="https://reactjs.org/docs/hooks-rules.html">Basic Rules</Link> when you use it.

<Playground
  desc="Pass the handler straight to onChange, or call it with a value."
  scope={{ Button, Input, Spacer, useInputState }}
  code={`
() => {
  const [value, setValue] = useInputState('')
  return (
    <>
      <Input placeholder="Type something" value={value} onChange={setValue} />
      <Spacer h={0.5} />
      <Button auto scale={0.6} onClick={() => setValue('')}>Clear</Button>
    </>
  )
}
`}
/>
