## useToggle

Switch between two or more values, a boolean by default.

This is custom React hooks, you need to follow the <Link target="_blank" color href="https://reactjs.org/docs/hooks-rules.html">Basic Rules</Link> when you use it.

<Playground
  desc="Without arguments it flips a boolean, with a list it cycles through the values."
  scope={{ Button, Spacer, useToggle }}
  code={`
() => {
  const [value, toggle] = useToggle()
  const [theme, toggleTheme] = useToggle(['light', 'dark', 'system'])
  return (
    <>
      <Button auto scale={0.6} onClick={() => toggle()}>{String(value)}</Button>
      <Spacer h={0.5} />
      <Button auto scale={0.6} onClick={() => toggleTheme()}>{theme}</Button>
    </>
  )
}
`}
/>
