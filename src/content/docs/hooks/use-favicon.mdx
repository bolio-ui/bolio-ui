## useFavicon

Set the favicon of the page and update it when the value changes.

This is custom React hooks, you need to follow the <Link target="_blank" color href="https://reactjs.org/docs/hooks-rules.html">Basic Rules</Link> when you use it.

<Playground
  desc="The icon of the tab follows the choice."
  scope={{ Button, useFavicon }}
  code={`
() => {
  const [url, setUrl] = React.useState('')
  const red = 'data:image/svg+xml,' + encodeURIComponent('<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 10 10"><circle cx="5" cy="5" r="5" fill="red"/></svg>')
  useFavicon(url)
  return <Button auto scale={0.6} onClick={() => setUrl(red)}>Use a red icon</Button>
}
`}
/>
