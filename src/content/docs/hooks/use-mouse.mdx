## useMouse

Track the position of the mouse, in the page or relative to an element.

This is custom React hooks, you need to follow the <Link target="_blank" color href="https://reactjs.org/docs/hooks-rules.html">Basic Rules</Link> when you use it.

<Playground
  desc="The position is relative to the box when the ref is used."
  scope={{ Text, useMouse }}
  code={`
() => {
  const { ref, x, y } = useMouse()
  return (
    <div ref={ref} style={{ padding: 24, border: '1px dashed currentColor' }}>
      <Text>{x}, {y}</Text>
    </div>
  )
}
`}
/>
