## useRovingIndex

Move the focus between the items of a list with the arrow keys, keeping one tab stop.

This is custom React hooks, you need to follow the <Link target="_blank" color href="https://reactjs.org/docs/hooks-rules.html">Basic Rules</Link> when you use it.

<Playground
  desc="Tab into the group once, then use the arrow keys."
  scope={{ useRovingIndex }}
  code={`
() => {
  const { getItemProps } = useRovingIndex({ total: 3 })
  return (
    <div>
      {['One', 'Two', 'Three'].map((label, index) => (
        <button key={label} {...getItemProps(index)} style={{ marginRight: 8 }}>{label}</button>
      ))}
    </div>
  )
}
`}
/>
