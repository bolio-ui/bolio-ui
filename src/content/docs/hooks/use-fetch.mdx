## useFetch

Request data with fetch and get the loading state, the error and a way to refetch or abort.

This is custom React hooks, you need to follow the <Link target="_blank" color href="https://reactjs.org/docs/hooks-rules.html">Basic Rules</Link> when you use it.

<Playground
  desc="Load a post when you click, with the loading state handled by the hook."
  scope={{ Button, Text, useFetch }}
  code={`
() => {
  const { data, loading, error, refetch } = useFetch('https://jsonplaceholder.typicode.com/posts/1', { autoInvoke: false })
  return (
    <>
      <Button auto scale={0.6} loading={loading} onClick={refetch}>Load post</Button>
      <Text>{error ? error.message : data ? data.title : 'Nothing loaded yet'}</Text>
    </>
  )
}
`}
/>

```ts
const useFetch = <T = unknown>(
  url: string,
  options?: RequestInit & { autoInvoke?: boolean },
) => {
  data: T | null
  loading: boolean
  error: Error | null
  refetch: () => Promise<T | null>
  abort: () => void
}
```
