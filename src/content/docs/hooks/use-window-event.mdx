## useWindowEvent

Attach an event listener to the window and remove it when the component unmounts.

This is custom React hooks, you need to follow the <Link target="_blank" color href="https://reactjs.org/docs/hooks-rules.html">Basic Rules</Link> when you use it.

<Playground
  desc="Show the last key pressed anywhere on the page."
  scope={{ Text, useWindowEvent }}
  code={`
() => {
  const [key, setKey] = React.useState('')
  useWindowEvent('keydown', (event) => setKey(event.key))
  return <Text>Last key: {key || 'none yet'}</Text>
}
`}
/>
