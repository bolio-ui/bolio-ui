## useScrollSpy

Highlight the heading that is visible while the page is scrolled, for a table of contents.

This is custom React hooks, you need to follow the <Link target="_blank" color href="https://reactjs.org/docs/hooks-rules.html">Basic Rules</Link> when you use it.

<Playground
  desc="Lists the h2 headings of the page and marks the one being read."
  scope={{ Text, useScrollSpy }}
  code={`
() => {
  const { active, data } = useScrollSpy({ selector: 'h2', offset: 80 })
  return (
    <>
      {data.slice(0, 6).map((heading, index) => (
        <Text key={heading.id + index} small b={index === active}>{heading.label}</Text>
      ))}
    </>
  )
}
`}
/>
