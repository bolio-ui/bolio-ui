## useMap

Keep a Map in state that renders again when it changes.

This is custom React hooks, you need to follow the <Link target="_blank" color href="https://reactjs.org/docs/hooks-rules.html">Basic Rules</Link> when you use it.

<Playground
  desc="set, delete and clear render the component again."
  scope={{ Button, Text, useMap }}
  code={`
() => {
  const map = useMap([['a', 1]])
  return (
    <>
      <Text>{[...map].map(([key, value]) => key + '=' + value).join(', ') || 'empty'}</Text>
      <Button auto scale={0.6} onClick={() => map.set('k' + map.size, map.size)}>Add</Button>
      <Button auto scale={0.6} onClick={() => map.clear()} style={{ marginLeft: 8 }}>Clear</Button>
    </>
  )
}
`}
/>
