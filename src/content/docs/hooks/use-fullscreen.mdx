## useFullscreen

Put an element, or the whole page, in fullscreen.

This is custom React hooks, you need to follow the <Link target="_blank" color href="https://reactjs.org/docs/hooks-rules.html">Basic Rules</Link> when you use it.

<Playground
  desc="Without a ref the whole page goes fullscreen."
  scope={{ Button, useFullscreen }}
  code={`
() => {
  const { ref, toggle, fullscreen } = useFullscreen()
  return (
    <div ref={ref} style={{ padding: 24 }}>
      <Button auto scale={0.6} onClick={toggle}>{fullscreen ? 'Exit fullscreen' : 'Enter fullscreen'}</Button>
    </div>
  )
}
`}
/>

```ts
const useFullscreen = <T extends HTMLElement = HTMLElement>() => {
  ref: RefObject<T | null>
  fullscreen: boolean
  enter: () => Promise<void>
  exit: () => Promise<void>
  toggle: () => Promise<void>
}
```
