## useWindowScroll

Read the scroll position of the window and scroll it.

This is custom React hooks, you need to follow the <Link target="_blank" color href="https://reactjs.org/docs/hooks-rules.html">Basic Rules</Link> when you use it.

<Playground
  desc="Read the scroll position and go back to the top."
  scope={{ Button, Text, useWindowScroll }}
  code={`
() => {
  const [scroll, scrollTo] = useWindowScroll()
  return (
    <>
      <Text>Scroll: {scroll.x}, {scroll.y}</Text>
      <Button auto scale={0.6} onClick={() => scrollTo({ y: 0 })}>Scroll to top</Button>
    </>
  )
}
`}
/>
