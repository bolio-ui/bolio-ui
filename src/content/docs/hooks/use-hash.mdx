## useHash

Read and set the hash of the URL and keep it updated.

This is custom React hooks, you need to follow the <Link target="_blank" color href="https://reactjs.org/docs/hooks-rules.html">Basic Rules</Link> when you use it.

<Playground
  desc="Change the hash and the value follows."
  scope={{ Button, Text, useHash }}
  code={`
() => {
  const [hash, setHash] = useHash()
  return (
    <>
      <Text>Hash: {hash || 'empty'}</Text>
      <Button auto scale={0.6} onClick={() => setHash('example')}>Set #example</Button>
    </>
  )
}
`}
/>
