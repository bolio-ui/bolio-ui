## useNetwork

Read the state of the connection and know when it goes online or offline.

This is custom React hooks, you need to follow the <Link target="_blank" color href="https://reactjs.org/docs/hooks-rules.html">Basic Rules</Link> when you use it.

<Playground
  desc="Turn the network off in the browser to see the status change. Connection details are not available in every browser."
  scope={{ Text, useNetwork }}
  code={`
() => {
  const network = useNetwork()
  return <Text>{network.online ? 'Online' : 'Offline'}, {network.effectiveType || 'unknown connection'}</Text>
}
`}
/>
