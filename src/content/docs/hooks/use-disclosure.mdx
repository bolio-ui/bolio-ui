## useDisclosure

Control the open state of a modal, drawer or any other disclosure, with optional callbacks.

This is custom React hooks, you need to follow the <Link target="_blank" color href="https://reactjs.org/docs/hooks-rules.html">Basic Rules</Link> when you use it.

<Playground
  desc="Open and close a modal from the handlers."
  scope={{ Button, Modal, useDisclosure }}
  code={`
() => {
  const [opened, { open, close }] = useDisclosure(false)
  return (
    <>
      <Button auto scale={0.6} onClick={open}>Open modal</Button>
      <Modal visible={opened} onClose={close}>
        <Modal.Title>Disclosure</Modal.Title>
        <Modal.Action passive onClick={close}>Close</Modal.Action>
      </Modal>
    </>
  )
}
`}
/>
