## useHover

Detect when the pointer is over an element.

This is custom React hooks, you need to follow the <Link target="_blank" color href="https://reactjs.org/docs/hooks-rules.html">Basic Rules</Link> when you use it.

<Playground
  desc="The text changes while the pointer is over the box."
  scope={{ Text, useHover }}
  code={`
() => {
  const { hovered, ref } = useHover()
  return (
    <div ref={ref} style={{ padding: 24, border: '1px dashed currentColor' }}>
      <Text>{hovered ? 'Hovered' : 'Hover me'}</Text>
    </div>
  )
}
`}
/>
