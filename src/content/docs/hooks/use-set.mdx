## useSet

Keep a Set in state that renders again when it changes.

This is custom React hooks, you need to follow the <Link target="_blank" color href="https://reactjs.org/docs/hooks-rules.html">Basic Rules</Link> when you use it.

<Playground
  desc="add, delete and clear render the component again."
  scope={{ Button, Text, useSet }}
  code={`
() => {
  const set = useSet(['a', 'b'])
  return (
    <>
      <Text>{[...set].join(', ') || 'empty'}</Text>
      <Button auto scale={0.6} onClick={() => set.add('item ' + (set.size + 1))}>Add</Button>
      <Button auto scale={0.6} onClick={() => set.clear()} style={{ marginLeft: 8 }}>Clear</Button>
    </>
  )
}
`}
/>
