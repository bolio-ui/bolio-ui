## useMergedRef

Merge several refs, callback or object, into one.

This is custom React hooks, you need to follow the <Link target="_blank" color href="https://reactjs.org/docs/hooks-rules.html">Basic Rules</Link> when you use it.

<Playground
  desc="One element is read by two refs."
  scope={{ Button, Text, useMergedRef }}
  code={`
() => {
  const first = React.useRef(null)
  const second = React.useRef(null)
  const ref = useMergedRef(first, second)
  const [same, setSame] = React.useState('')
  return (
    <>
      <div ref={ref}>Merged</div>
      <Button auto scale={0.6} onClick={() => setSame(String(first.current === second.current))}>Compare</Button>
      <Text>Same element: {same}</Text>
    </>
  )
}
`}
/>
