## useLogger

Log the mount, the updates and the unmount of a component with its props, for debugging.

This is custom React hooks, you need to follow the <Link target="_blank" color href="https://reactjs.org/docs/hooks-rules.html">Basic Rules</Link> when you use it.

<Playground
  desc="Open the console to see the logs."
  scope={{ Button, useLogger }}
  code={`
() => {
  const [count, setCount] = React.useState(0)
  useLogger('Counter', [count])
  return <Button auto scale={0.6} onClick={() => setCount(count + 1)}>Count {count}</Button>
}
`}
/>
