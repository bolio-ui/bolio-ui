## useDebouncedState

Keep a state whose updates are applied only after the user stops changing it.

This is custom React hooks, you need to follow the <Link target="_blank" color href="https://reactjs.org/docs/hooks-rules.html">Basic Rules</Link> when you use it.

<Playground
  desc="The value changes 500ms after the last keystroke."
  scope={{ Text, Input, Spacer, useDebouncedState }}
  code={`
() => {
  const [value, setValue] = useDebouncedState('', 500)
  return (
    <>
      <Input placeholder="Type something" onChange={(e) => setValue(e.target.value)} />
      <Spacer h={0.5} />
      <Text>Value: {value}</Text>
    </>
  )
}
`}
/>
