## useThrottledState

Keep a state that updates at most once per interval.

This is custom React hooks, you need to follow the <Link target="_blank" color href="https://reactjs.org/docs/hooks-rules.html">Basic Rules</Link> when you use it.

<Playground
  desc="The click count shows at most one update per second."
  scope={{ Button, Text, useThrottledState }}
  code={`
() => {
  const [count, setCount] = useThrottledState(0, 1000)
  const clicks = React.useRef(0)
  return (
    <>
      <Button auto scale={0.6} onClick={() => setCount(++clicks.current)}>Click fast</Button>
      <Text>Shown: {count}</Text>
    </>
  )
}
`}
/>
