## useIdle

Detect when the user has not interacted with the page for a while.

This is custom React hooks, you need to follow the <Link target="_blank" color href="https://reactjs.org/docs/hooks-rules.html">Basic Rules</Link> when you use it.

<Playground
  desc="Stay still for three seconds."
  scope={{ Text, useIdle }}
  code={`
() => {
  const idle = useIdle(3000, { initialState: false })
  return <Text>{idle ? 'Idle' : 'Active'}</Text>
}
`}
