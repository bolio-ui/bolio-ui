## useIsFirstRender

Know whether the component is rendering for the first time.

This is custom React hooks, you need to follow the <Link target="_blank" color href="https://reactjs.org/docs/hooks-rules.html">Basic Rules</Link> when you use it.

<Playground
  desc="It is true only on the first render."
  scope={{ Button, Text, useIsFirstRender }}
  code={`
() => {
  const first = useIsFirstRender()
  const [, setCount] = React.useState(0)
  return (
    <>
      <Text>First render: {String(first)}</Text>
      <Button auto scale={0.6} onClick={() => setCount((c) => c + 1)}>Render again</Button>
    </>
  )
}
`}
/>
