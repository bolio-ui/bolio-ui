## useActiveElement

Read the element that has focus right now.

This is custom React hooks, you need to follow the <Link target="_blank" color href="https://reactjs.org/docs/hooks-rules.html">Basic Rules</Link> when you use it.

<Playground
  desc="Focus the input, then click elsewhere."
  scope={{ Input, Text, useActiveElement }}
  code={`
() => {
  const active = useActiveElement()
  return (
    <>
      <Input aria-label="Name" placeholder="Focus me" />
      <Text>Focused: {active ? active.tagName.toLowerCase() : 'nothing'}</Text>
    </>
  )
}
`}
/>
