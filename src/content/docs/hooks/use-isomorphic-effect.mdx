## useIsomorphicEffect

Use useLayoutEffect in the browser and useEffect on the server, without the warning.

This is custom React hooks, you need to follow the <Link target="_blank" color href="https://reactjs.org/docs/hooks-rules.html">Basic Rules</Link> when you use it.

<Playground
  desc="Measure an element before the browser paints."
  scope={{ Text, useIsomorphicEffect }}
  code={`
() => {
  const ref = React.useRef(null)
  const [width, setWidth] = React.useState(0)
  useIsomorphicEffect(() => setWidth(ref.current.offsetWidth), [])
  return <div ref={ref}><Text>Width: {width}px</Text></div>
}
`}
