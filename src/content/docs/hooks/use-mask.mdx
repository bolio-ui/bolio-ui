## useMask

Format the value of an input with a mask, such as a phone number or a date.

This is custom React hooks, you need to follow the <Link target="_blank" color href="https://reactjs.org/docs/hooks-rules.html">Basic Rules</Link> when you use it.

<Playground
  desc="# is a digit, A is a letter and * is any of them."
  scope={{ Input, useMask }}
  code={`
() => {
  const [phone, setPhone] = useMask({ mask: '(###) ###-####' })
  return <Input placeholder="(555) 123-4567" value={phone} onChange={setPhone} />
}
`}
/>
