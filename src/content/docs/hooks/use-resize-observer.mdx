## useResizeObserver

Observe the size and position of an element with a ResizeObserver.

This is custom React hooks, you need to follow the <Link target="_blank" color href="https://reactjs.org/docs/hooks-rules.html">Basic Rules</Link> when you use it.

<Playground
  desc="Resize the textarea to see its size change."
  scope={{ Text, useResizeObserver }}
  code={`
() => {
  const [ref, rect] = useResizeObserver()
  return (
    <>
      <Text>{Math.round(rect.width)} x {Math.round(rect.height)}</Text>
      <textarea ref={ref} style={{ resize: 'both', width: 240, height: 80 }} />
    </>
  )
}
`}
/>
