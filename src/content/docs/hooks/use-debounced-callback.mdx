## useDebouncedCallback

Create a function that runs only after it stops being called for the given time.

This is custom React hooks, you need to follow the <Link target="_blank" color href="https://reactjs.org/docs/hooks-rules.html">Basic Rules</Link> when you use it.

<Playground
  desc="The callback runs once, 400ms after the last click."
  scope={{ Button, Text, Spacer, useDebouncedCallback }}
  code={`
() => {
  const [count, setCount] = React.useState(0)
  const [clicks, setClicks] = React.useState(0)
  const save = useDebouncedCallback((value) => setCount(value), 400)
  return (
    <>
      <Button auto scale={0.6} onClick={() => { setClicks(clicks + 1); save(clicks + 1) }}>Click</Button>
      <Spacer h={0.5} />
      <Text>Clicks: {clicks}, saved: {count}</Text>
    </>
  )
}
`}
/>
