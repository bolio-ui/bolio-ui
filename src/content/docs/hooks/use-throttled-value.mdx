## useThrottledValue

Limit how often a value updates, no more than once per interval.

This is custom React hooks, you need to follow the <Link target="_blank" color href="https://reactjs.org/docs/hooks-rules.html">Basic Rules</Link> when you use it.

<Playground
  desc="The throttled value updates at most once per second."
  scope={{ Text, Input, Spacer, useThrottledValue }}
  code={`
() => {
  const [value, setValue] = React.useState('')
  const throttled = useThrottledValue(value, 1000)
  return (
    <>
      <Input placeholder="Type fast" value={value} onChange={(e) => setValue(e.target.value)} />
      <Spacer h={0.5} />
      <Text>Throttled: {throttled}</Text>
    </>
  )
}
`}
/>
