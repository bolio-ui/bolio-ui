## useDebouncedValue

Delay a value until it stops changing for the given time.

This is custom React hooks, you need to follow the <Link target="_blank" color href="https://reactjs.org/docs/hooks-rules.html">Basic Rules</Link> when you use it.

<Playground
  desc="The debounced value follows the input 500ms after the last keystroke."
  scope={{ Text, Input, Spacer, useDebouncedValue }}
  code={`
() => {
  const [value, setValue] = React.useState('')
  const [debounced] = useDebouncedValue(value, 500)
  return (
    <>
      <Input placeholder="Type something" value={value} onChange={(e) => setValue(e.target.value)} />
      <Spacer h={0.5} />
      <Text>Debounced: {debounced}</Text>
    </>
  )
}
`}
/>
