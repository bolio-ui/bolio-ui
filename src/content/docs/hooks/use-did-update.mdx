## useDidUpdate

Run an effect only when the dependencies change, not on the first render.

This is custom React hooks, you need to follow the <Link target="_blank" color href="https://reactjs.org/docs/hooks-rules.html">Basic Rules</Link> when you use it.

<Playground
  desc="The counter of updates ignores the first render."
  scope={{ Button, Text, useDidUpdate }}
  code={`
() => {
  const [count, setCount] = React.useState(0)
  const [updates, setUpdates] = React.useState(0)
  useDidUpdate(() => setUpdates((u) => u + 1), [count])
  return (
    <>
      <Text>Count: {count}, updates: {updates}</Text>
      <Button auto scale={0.6} onClick={() => setCount(count + 1)}>Increment</Button>
    </>
  )
}
`}
/>
